# Hiyori 桌面悬浮宠物 (Electron)

把 Lord King 的网页前端，以**透明、无边框、始终置顶**的小窗放到桌面角落，变成一只能说话、有表情、记得你的桌宠。

它**不重写任何业务逻辑** —— 直接加载现有前端的"宠物模式"（`?pet=1`），所以 Live2D、语音、好感度、记忆画像、主动搭话全部原样复用。

## 前提

后端 + 前端服务已经跑起来（`docker compose up -d`）。宠物窗口连的就是这个服务。

## 运行（开发）

```bash
cd desktop
npm install
npm start
```

默认连 `http://110.42.217.122`（你的服务器，nginx 80 端口）。如果要连别的地址：

```bash
# Windows PowerShell
$env:LORDKING_URL="http://192.168.1.10"; npm start
```

也可以编辑配置文件（首次运行后生成）：
`%APPDATA%/lordking-pet/config.json` → 改 `url` 字段。

## 打包成 .exe

```bash
cd desktop
npm install
npm run dist:win
```

产物在 `desktop/dist/`，双击安装后桌面/开始菜单就有 HiyoriPet。

## 使用

- **移动**：拖窗口顶部一条（隐形拖拽区）即可挪动；位置会被记住。
- **说话**：鼠标悬停时底部会浮出输入条，打字回车即可；点角色本体可触发语音输入。
- **托盘菜单**（右下角花花图标右键）：
  - 显示 / 隐藏
  - 始终置顶（开关）
  - 鼠标穿透（锁定后点击会穿过宠物落到桌面，适合不想被挡住时；要重新交互就在托盘里取消勾选）
  - 打开完整界面（在默认浏览器里打开完整版网页）
  - 重新加载 / 退出
- 关闭窗口不会退出，程序留在托盘；退出请用托盘菜单。

## 登录

首次没登录时，宠物窗口会显示登录卡片，登录后自动刷新进入宠物形态（凭据存在该窗口的 localStorage，下次免登录）。

## 已知限制

- **语音输入**依赖 Chromium 的 `webkitSpeechRecognition`，在部分 Electron 构建里可能不稳定（连不上 Google 语音服务）。**语音输出（Edge TTS）、口型、表情、文字对话都正常**。语音不灵时用底部输入条即可。
- 透明窗口的"空白区域"仍会挡住下层鼠标点击，这是系统行为；需要不挡操作时用托盘的"鼠标穿透"。
